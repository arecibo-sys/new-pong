# Neon Pulse Pong

A browser-based advanced Pong game with power-ups, neon visuals, and procedural acid techno music.

## Play now

[https://arecibo-sys.github.io/new-pong/](https://arecibo-sys.github.io/new-pong/)

## Features

- Smooth responsive canvas scaling for desktop and mobile
- Player vs AI with adaptive difficulty
- Power-ups that drop during rallies:
  - **BIG** — enlarges your paddle
  - **MINI** — shrinks the opponent's paddle
  - **FAST** — speeds up the ball on your next hit
  - **SLOW** — slows the opponent temporarily
- Procedural acid techno soundtrack generated in real time with Web Audio
- Neon particle effects, screen shake, and glowing UI
- First to 7 wins

## Controls

- **Mouse / touch drag** — move your paddle
- **↑ / ↓ arrow keys** or **W / S** — move your paddle
- **Enter / click / tap** — start or serve

## How to run locally

Open `index.html` in any modern web browser. No build step or dependencies required.
